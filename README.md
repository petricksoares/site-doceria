## 💡 Sobre o Projeto

O **Delícias da Ju** é um site de cardápio e apresentação para uma confeitaria artesanal localizada em Teresina, Piauí. O projeto foi desenvolvido com foco em design atraente, usabilidade mobile e conversão direta para o WhatsApp, facilitando encomendas de bolos para aniversários, festas e datas especiais.

---

## Funcionalidades

- **Cardápio interativo** com galeria de bolos, descrições e preços
- **Modal de detalhes** ao clicar em qualquer bolo — exibe foto ampliada, descrição completa e botão de pedido direto no WhatsApp
- **"Ver todos os bolos"** — expande a grade para exibir o catálogo completo com animação suave
- **Integração com WhatsApp** — botões de encomenda linkam diretamente para o número da confeiteira
- **Navegação suave** com scroll animado entre seções
- **Menu hambúrguer** responsivo para dispositivos móveis
- **Seção Sobre** com foto da confeiteira e diferenciais do negócio
- **Footer completo** com formas de pagamento (Pix e cartão) e redes sociais

## 🎨 Layout

O design segue uma identidade visual delicada e feminina com a seguinte paleta:

| Cor | Hex | Uso |
|-----|-----|-----|
| Rosa claro | `#fce8f0` | Fundo do hero e seção sobre |
| Rosa médio | `#f5c6d8` | Bordas e detalhes |
| Rosa forte | `#e05585` | Botões, preços e destaques |
| Marrom escuro | `#3b1a0e` | Títulos e textos principais |

**Fontes utilizadas:**
- [Pacifico](https://fonts.google.com/specimen/Pacifico) — títulos e nomes dos bolos
- [Lato](https://fonts.google.com/specimen/Lato) — textos e interface

---

## 🛠 Tecnologias

As seguintes tecnologias foram utilizadas no projeto:

- **HTML5** — estrutura semântica das páginas
- **CSS3** — estilização, animações, gradientes e layout com Flexbox e Grid
- **JavaScript (Vanilla)** — interatividade (modal, menu mobile, toggle de bolos)
- **Google Fonts** — tipografia (Pacifico + Lato)

> Nenhuma biblioteca ou framework externo foi utilizado. O projeto roda com arquivos estáticos puros.

## 🚀 Como Usar

Não é necessário instalar nada. Por ser um projeto estático, basta:

**1. Clonar o repositório**
```bash
git clone https://github.com/seu-usuario/delicias-da-ju.git
```

**2. Entrar na pasta**
```bash
cd delicias-da-ju
```

**3. Abrir no navegador**

Abra o arquivo `index.html` diretamente no navegador, ou use uma extensão como o **Live Server** no VS Code para visualização em tempo real.

## 📱 Responsividade

O site foi desenvolvido com design responsivo para funcionar em diferentes tamanhos de tela:

| Dispositivo | Largura | Comportamento |
|-------------|---------|---------------|
| Desktop | > 1024px | Layout completo em duas colunas |
| Tablet | 768px – 1024px | Grid de bolos reduzido para 2 colunas |
| Mobile | < 768px | Layout empilhado, menu hambúrguer ativo |
| Mobile pequeno | < 400px | Grid de bolos em coluna única |
